Ton mode de démarrage

Deux façons d'utiliser Shift180 · ↔ glisse les cartes

Posé ✓ Mode hors ligne

Sans compte et sans Internet, via ton propre dossier ou fichier

Tout tourne depuis ton appareil : sur PC tu clones le dépôt GitHub complet ; sur téléphone / tablette tu télécharges un seul fichier HTML à ouvrir — rien d'autre. Ta progression est gardée dans le navigateur de l'appareil.

Posé ✓ Mode en ligne

Avec un compte : progression synchronisée sur tous tes appareils

Tu crées ton compte (Google, GitHub ou email) et ta progression est sauvegardée dans le cloud. Changé de téléphone ? Ton tableau est déjà là — et le mode hors ligne reste toujours possible en plus.
