Comment veux-tu commencer ?

Deux modes interchangeables — tu peux commencer hors ligne et connecter un compte plus tard.

Recommandé sur ton appareil

1. Le fichier unique (téléphone, tablette, PC)

Un seul fichier shift180-hors-ligne.html contient toute la plateforme : les 6 mois, les leçons, le lexique, l'éditeur. Ni Internet, ni Git, ni dossier entier.

  1. Télécharge le fichier (bouton ci-dessous depuis la plateforme en ligne, ou sur PC).
  2. Ouvre-le dans Chrome / Firefox (sur Android : Fichiers → Ouvrir avec → Chrome ; sur iPhone : Safari sait ouvrir un HTML depuis Fichiers).
  3. La plateforme s'ouvre telle quelle : personnalise ton chemin, jour après jour.
⤓ Télécharger le fichier unique

Sur iPhone/iPad, la sauvegarde de progression dans ce fichier peut être limitée par Safari : le mode en ligne reste la meilleure option iOS. Sur Android/PC, tout est gardé localement.

2. Cloner le dépôt complet (PC obligatoire, le plus fidèle)

  1. Installe Git (git-scm.com, 5 minutes).
  2. Ouvre un terminal et tape : git clone https://github.com/<ton-dep>/Shift180.git → un dossier Shift180 apparaît.
  3. Ouvre index.html (double-clic) : c'est prêt

pas de PC ? Saute cette étape pour l'instant : elle attendra ta prochaine session PC.

Et ensuite ?

Quand tu te connectes à un compte (mode en ligne), ta progression hors ligne, déjà stockée localement, se synchronise automatiquement — rien ne se perd.

Ton tableau suit l'appareil : smartphone, tablette, PC — ta progression est sauvegardée en ligne dès validation. Hors connexion ? File d'attente automatique, retour de réseau inclus.
